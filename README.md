# AbilisPath - Modern Education Consultancy Website

A premium, production-ready, SEO-optimized education consultancy website built with Next.js 14, Tailwind CSS, Framer Motion, and modern best practices. Founder: Arvind | Location: Chennai, India

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Forms:** React Hook Form + Zod validation
- **Language:** TypeScript
- **Data:** Mock JSON (CMS-ready)

## Design System

- **Primary Color:** #1E4D8C (Deep Blue)
- **Accent Color:** #E85D26 (Orange)
- **Background:** White
- **Fonts:** Poppins (Headings), Inter (Body)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)
